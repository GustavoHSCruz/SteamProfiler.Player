INSTALAÇÃO

Sem framework e sem dependências

Importe o módulo, inclua a folha de estilos e entregue um elemento onde o player será montado.

import {
  steamTrailer,
  mountTrailer
} from '@steamprofiler/player';

const data = await steamTrailer(620);
const player = mountTrailer(
  document.querySelector('#video'),
  data
);

await player.ready;

Responsabilidades separadas. O pacote desenha e controla vídeo. A API pública converte uma App ID em metadados e fontes fornecidas pela Steam. Nenhuma chave da Steam chega ao navegador.

Atribuição. Distribuições deste componente mantêm a marca e o link visíveis para steamprofiler.org, conforme a licença do repositório.
